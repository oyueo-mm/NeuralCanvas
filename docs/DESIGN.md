# 디자인: Minimal Scientific Workspace

기본 배경 `#F8FAFC`, 표면 `#FFFFFF`, 본문 `#182235`, 보조 텍스트 `#617086`, 경계선 `#E2E8F0`, 강조색 `#2563EB`를 사용합니다. 데이터 점은 청록색, 예측 곡선은 파란색, 관찰 입력과 검증 표본은 주황색으로 구분합니다. 시스템 산세리프와 숫자용 시스템 모노스페이스를 사용하며 과도한 자간과 장식 영문 레이블을 제거했습니다.

## 정보 구조

- 64px 데스크톱 툴바, 간결한 실험 상태, 나란히 놓인 데이터·신경망, 공통 관찰 바, 학습 도크, 기본 접힌 분석 순서입니다.
- 900px 이하에서는 56px 툴바와 데이터/신경망/분석 탭을 제공합니다. 기본은 데이터 한 화면이며, 학습 도크는 작업 영역 아래에 항상 남습니다.
- 그래프 크기는 ResizeObserver와 flex 레이아웃으로 계산합니다. 100dvh와 safe-area-inset을 사용하며 모바일에서 전체 콘텐츠를 세로로 쌓지 않습니다.
- 데이터·모델·학습 설정·관찰 설정·파일 메뉴는 데스크톱 우측 드로어, 모바일 바텀시트로 표시합니다. 선택한 점의 좌표와 삭제, 선택한 연결·뉴런의 Inspector를 편집 화면 상단에 둡니다.

## 직접 조작

데이터의 점 편집과 화면 탐색을 명확히 분리합니다. 점 이동은 로컬 미리보기 후 손을 놓을 때 한 번만 커밋하여 한 번의 실행 취소로 되돌립니다. 두 손가락이 감지되면 점 추가·이동을 취소하고 뷰포트 확대·이동으로 전환합니다. 신경망도 한 손가락 이동, 두 손가락 확대, 버튼·휠 확대와 화면 맞춤을 지원합니다. 모든 뷰포트 조작은 실제 모델과 데이터를 변경하지 않습니다.

학습 점은 채운 원, 검증 점은 주황색 테두리 원입니다. 신경망 양수 가중치는 파란 실선, 음수는 주황색 파선, 비활성은 회색 점선입니다. 숫자·부호·범례·Inspector로 색 외의 정보도 제공합니다. 복잡하게 겹친 점과 연결은 편집 패널의 선택 목록으로도 접근합니다.

숫자는 비활성 상태에서 적절한 유효숫자로 표시하고, 포커스하면 원본 전체 정밀도를 선택합니다. 저장값은 반올림하지 않습니다. 실험 JSON v1 형식은 유지합니다.

## 접근성과 모바일

주요 모바일 버튼과 입력은 44px 이상입니다. iOS 자동 확대를 피하도록 모바일 숫자 입력은 16px이며 numeric/decimal 입력 모드를 제공합니다. dialog.showModal을 사용해 배경을 비활성화하고 포커스를 가둡니다. Esc·닫기·바깥 영역으로 닫을 수 있고, 열기 전 버튼 또는 그래프로 포커스를 복원합니다. WebKit의 포인터 클릭 포커스 차이도 처리합니다.

바텀시트 내부는 독립 스크롤이며 visualViewport 높이 변화에 맞춰 최대 높이를 제한합니다. 고정 도크는 모달 뒤에서 비활성화되므로 입력 필드를 덮지 않습니다. Reduced Motion에서는 CSS 전환과 애니메이션을 제거합니다. 입력 순회는 사용자가 명시적으로 실행한 경우에만 동작합니다.

실제 휴대전화·실제 OS 키보드 검증은 수행하지 않았습니다. Playwright 터치 에뮬레이션, Chromium 멀티터치 입력, 작은 뷰포트로 키보드 높이를 모사한 검증과 구분합니다. 자세한 비교는 [UI 개편 보고서](UI_REDESIGN.md)를 참고하세요.
