# 디자인

깊은 녹색 바탕, 라임색 모델 예측, 보라색 데이터·음수 연결, 황토색 관찰 입력을 사용합니다. 네트워크 연결은 부호·제한된 두께·숫자 툴팁·비활성 점선으로 표현합니다. 색 외에도 숫자와 선 형태로 상태를 제공합니다.

데스크톱은 왼쪽 데이터 캔버스와 오른쪽 신경망·모델 설정을 배치합니다. 아래에는 입력 순회와 손실 분석을 둡니다. 760px 이하에서는 세로 배치 및 전체/데이터/신경망 탭을 제공합니다. 설정·분석·설명은 details로 접을 수 있습니다.

데이터 편집 모드와 화면 탐색 모드를 분리합니다. 확대·이동은 화면 좌표계만 변경하고 실제 데이터 좌표를 수정하지 않습니다. 연결·뉴런에는 키보드 Enter 선택을 제공하고 폼과 버튼은 이름·포커스 표시를 갖습니다.

입력 순회는 가중치를 변경하지 않습니다. 현재 입력을 왼쪽 보조선·점 및 오른쪽 실제 활성화 값으로 연결합니다. 층 강조는 순전파 순서를 보여주는 교육적 비유이며 실제 정보가 물리적으로 이동하는 애니메이션이 아님을 UI에 설명합니다.

현재 제한: 핀치 확대와 선택 뉴런 중심 확대는 후속 작업입니다. 네트워크의 버튼·휠 확대 및 빈 배경 드래그 이동을 지원합니다. 출력이 화면 범위 밖이면 곡선을 클리핑하며 데이터 화면 맞춤은 현재 데이터 범위를 기준으로 합니다.
