# 수학 엔진

입력 x 하나와 출력 y 하나를 사용하는 MLP입니다. 모든 계산은 JavaScript number(IEEE 754 double)로 수행합니다.

## 순전파

`a⁰ = [x]`, `zˡⱼ = Σᵢ mˡⱼᵢ wˡⱼᵢ aˡ⁻¹ᵢ + bˡⱼ`, `aˡⱼ = φˡ(zˡⱼ)`입니다. m은 연결 활성화 마스크이며 꺼진 연결은 0입니다. forward는 각 층의 z, a 및 최종 예측을 반환합니다. 학습·시각화·입력 순회가 동일한 함수를 사용합니다. 입력/출력 정규화는 적용하지 않으며 화면 좌표 변환은 학습 데이터와 독립적입니다.

## 활성화

| 함수 | 값 | 미분 |
| --- | --- | --- |
| Linear | z | 1 |
| Tanh | tanh(z) | 1−tanh²(z) |
| Sigmoid | 1/(1+exp(−z)) | σ(z)(1−σ(z)) |
| ReLU | max(0,z) | z>0이면 1, 아니면 0 |
| Leaky ReLU | z>0이면 z, 아니면 0.01z | z>0이면 1, 아니면 0.01 |

Sigmoid는 z의 부호에 따라 식을 나누어 exp 오버플로를 방지합니다. ReLU 0에서 미분은 0, Leaky ReLU 0에서는 0.01로 정의합니다.

## 역전파

손실은 `L = (1/N)Σ(ŷ−y)²`입니다. 출력 활성화의 미분 이전 기울기는 `2(ŷ−y)/N`입니다. 각 층에서 `δ = (∂L/∂a) φ′(z)`, `∂L/∂wⱼᵢ = δⱼ aᵢ mⱼᵢ`, `∂L/∂bⱼ = δⱼ`, `∂L/∂aᵢ = Σⱼ wⱼᵢ δⱼ mⱼᵢ`를 누적합니다. 배치를 두 배로 복제해도 평균 기울기는 같습니다. Inspector의 ∂L/∂z는 마지막 배치에서 표본별 값을 합산한 결과입니다.

## Optimizer

SGD는 `θ ← θ − ηg`입니다. Adam은 `mₜ=.9mₜ₋₁+.1g`, `vₜ=.999vₜ₋₁+.001g²`, `m̂=mₜ/(1−.9ᵗ)`, `v̂=vₜ/(1−.999ᵗ)`, `θ ← θ−η m̂/(√v̂+10⁻⁸)`입니다. t는 파라미터별이 아닌 배치 업데이트별로 1 증가합니다. 비활성 가중치는 기존 Adam 모멘트가 있어도 업데이트하지 않습니다.

클리핑은 선택적 **성분별** `[-clip,+clip]` 제한입니다. global norm clipping은 아닙니다. 0이면 비활성입니다. Inspector에는 클리핑 전 기울기를 표시합니다.

## 초기화와 재현성

시드 PRNG와 Box–Muller 정규분포를 사용합니다. Xavier 가중치는 평균 0, 표준편차 `sqrt(2/(fanIn+fanOut))`, He는 `sqrt(2/fanIn)`입니다. 편향은 0입니다. Zero는 모든 가중치를 0으로 만들며 은닉 뉴런 대칭성을 깨지 못할 수 있습니다. 동일한 시드·데이터·설정·배치 수에서는 같은 계산을 반복합니다. 실행 시간만으로 재현성을 비교하지 않습니다.

## 유한차분

각 파라미터를 ±10⁻⁵로 섭동하여 `(L(θ+ε)−L(θ−ε))/(2ε)`를 분석 기울기와 비교합니다. 모든 가중치·편향을 검사하며 비활성 연결도 포함합니다. 절대오차 <10⁻⁸ 또는 상대오차 <10⁻⁴를 통과 조건으로 사용합니다. 상대오차 분모는 `max(10⁻⁷, |g_numeric|+|g_analytic|)`입니다. ReLU의 비미분 지점에 이 기준을 적용하지 않습니다.
